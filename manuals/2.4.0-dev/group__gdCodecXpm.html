XPM

XPM Reading

Read X PixMap images.

XPM support reads X PixMap files through libXpm and returns palette images. Unlike most gd image readers, the XPM API takes a filename string rather than a FILE pointer, memory buffer, or gd IO context. The returned image is owned by the caller. gd does not provide an XPM writer.

gdImagePtr im;
im = gdImageCreateFromXpm("icon.xpm");
if (im == NULL) {
return 1;
}
gdImageDestroy(im);

gdImagePtr gdImageCreateFromXpm ( char *  filename)

Create a palette image from an XPM file.

gdImageCreateFromXpm() reads filename directly through libXpm. The input is a filename, not an open FILE stream. On success, the returned image is owned by the caller and must be destroyed with gdImageDestroy().

Parameters
filenamePath to the XPM file to read.
Returns
A newly allocated palette image, or NULL on error.
