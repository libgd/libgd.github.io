Detailed Description

Options for writing TIFF data with the gdTiffWrite*() API.

Initialize with gdTiffWriteOptionsInit() before setting fields. NULL options use defaults: 8-bit RGBA, Adobe Deflate compression, inch resolution units, 72x72 resolution, and unassociated alpha.
