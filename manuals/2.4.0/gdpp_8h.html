Detailed Description

Object Oriented C++ wrappers around libgd functionality.

Example usage, convert png to gif: #include <fstream> #include <gdpp.h>

std::ifstream in("image.png", std::ios_base::in | std::ios_base::binary ); GD::Image im(in, GD::Png_tag()); if (im.good()) { std::ofstream out("image.gif", std::ios_base::out | std::ios_base::binary ); im.Gif(out); }
